# Where the gallery files come from

Everything here was made from the owner's own public project,
[blackhole-rust](https://github.com/qwertyboy0325/blackhole-rust), by resizing and
converting its output (macOS `sips`). Nothing was edited. Nothing is a third-party
image.

| File | What it is | Original |
|---|---|---|
| `black-hole-presentation.jpg` (+ `-thumb`) | the picture prepared for viewing, 1024 px | `artifacts/gate-2d0-presentation/review-1024/beauty-srgb16.png` |
| `black-hole-scene.jpg` (+ `-thumb`) | a later stage with more surroundings, 640 px | `artifacts/gate-2d1-scene-appearance/d1-v1-512/beauty-scene-srgb16.png` |
| `black-hole-diagnostic.jpg` (+ `-thumb`) | an early check image that labels itself "not a beauty render" | `docs/media/evolution-frames/frame-08.png` |
| `black-hole-evolution.mp4` | the project's stage-by-stage animation | `docs/media/blackhole-rust-evolution.mp4` (copied as is) |
| `black-hole-evolution-poster.jpg` (+ `-thumb`) | the last frame of that animation, used as the poster | `docs/media/evolution-frames/frame-16.png` |

The `artifacts/` renders are generated by the project and are not committed to its
public repository; they are the owner's own output. To refresh a picture, convert the
new render the same way (for example
`sips -s format jpeg -s formatOptions 82 -Z 1024 in.png --out out.jpg`) and update the
width/height in `src/content.js` (a test checks they match the file).

## Photographs

The owner's own photographs (Nikon Z 6), taken on one day in February 2025, chosen by the
owner for this site. Each went through `node scripts/add-photo.mjs`, which converts to sRGB,
fixes rotation, resizes to 1600 px (thumbnail 480 px) and removes all metadata (GPS position,
serial numbers, owner name, embedded thumbnail); only the camera, lens, focal length,
aperture, shutter and ISO are kept, as text in `src/content.js`. Nothing is from anyone
else's work. The people in the pictures are shown with the owner's decision to publish them.
